# Printable and fillable weekly course packets

The Northern Hardwoods & Mixedwoods course is also available as ten large-format learner PDFs. These editions are meant for printing, offline study, instructor-led classes, field binders, or anyone who works better with a document beside them than another browser tab.

Each packet contains the week's objectives, species instruction atlas, cumulative reference material, five-session workflow, fillable retrieval prompts, multi-organ practice, image credits, and instructional references. Form fields work in most desktop PDF readers, and every response area also prints cleanly.

> **Assessment integrity:** These are public learner editions. Secure graded examination specimens and instructor answer keys are deliberately excluded. Complete the graded practicals, midterm, and final inside the [online course](/course/) when you are ready.

## How to use the PDF version

- Read the labeled species material before attempting the retrieval pages.
- Cover or close the instructional atlas during closed-book work.
- Enter either a common name or scientific name for ordinary identification prompts unless nomenclature is explicitly being tested.
- Use the evidence, nearest-alternative, and requested-view fields when you want fuller field-decision practice.
- Return to the online course for shuffled secure assessments, grading, mastery tracking, and spaced remediation.

The PDF packets are an alternative way to work through the instruction, not an easier version of the course. The same standard applies: identify the narrowest rank the visible evidence can defend.
