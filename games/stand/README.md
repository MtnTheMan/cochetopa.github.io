# Stand on Cochetopa.co

This directory contains the public, versioned browser builds of *Stand*.

## v0.0.2 — current

- Public launcher: `/games/stand/`
- Static runtime: `/games/stand/v0.0.2/`
- Playable species: sugar maple
- Place: Oneida County, Wisconsin Working runtime field
- Browser persistence: two local IndexedDB generations plus JSON export/import
- Upstream project: `MtnTheMan/Stand`

The other 29 accepted botanical families appear only as deterministic,
non-playable ambient scenery. Their optimized transparent foliage derivatives
do not assert local ecology, suitability, occupancy, or species composition.
The compact Oneida field is real geographic context but remains explicitly not
fitted MaxEnt suitability or calibrated production ecology.

## v0.0.1 — preserved

- Static runtime: `/games/stand/v0.0.1/`
- Upstream project: `MtnTheMan/Stand`
- Source build: Stand v0.0.1 Alpha (`e6a718c`)

The original v0.0.1 files and URL remain unchanged. The two browser versions
use separate versioned paths and storage keys, so v0.0.2 does not overwrite the
older runtime or its browser save.
