# Stand on Cochetopa.co

This directory contains the public, versioned browser builds of *Stand*.

## v0.0.1

- Public launcher: `/games/stand/`
- Static runtime: `/games/stand/v0.0.1/`
- Upstream project: `MtnTheMan/Stand`
- Source build: Stand v0.0.1 Alpha (`e6a718c`)

The runtime remains modular so later builds can be added beside v0.0.1 without overwriting existing saves or URLs. The Cochetopa.co copy removes redundant prototype-data notices from the visible interface; simulation rules and gameplay behavior are otherwise unchanged.
